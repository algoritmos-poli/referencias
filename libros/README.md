# Libros de referencia

En el siguiente directorio se encuentran varios libros que pueden ser de utilidad para profinduzar los temas vistos en el curso.

## Textos principales

1. Joyanes Aguilar, L., & Zahonero Martínez, I. (2008). *Estructuras de datos en Java*. McGraw-Hill.
2. Joyanes Aguilar, L., & Zahonero Martínez, I. (2011). *Programación en Java 6: Algoritmos, programación orientada a objetos*. McGraw-Hill.
3. Cadenhead, R. (2020). *Sams teach yourself Java in 21 days* (8.ª ed.). Pearson Education, Inc.
4. Sedgewick, R., & Wayne, K. (2016). *Computer Science: An Interdisciplinary Approach*. Addison-Wesley Professional.
5. Lambert, K. A. (2009). *Fundamentals of Python: From First Programs through Data Structures*. Course Technology.
